# ezbudget – Frontend

React 19 + TypeScript (Vite), eigenes CSS-Design-System, kein Tailwind.

Setup und Zusammenspiel mit dem Django-Backend sind im [Haupt-README](../README.md)
beschrieben (Abschnitte 2 und 3.2).

```bash
npm install
npm run dev      # http://localhost:5173, proxied gegen das Backend auf :8000
npm run build    # Produktions-Build nach dist/
```
